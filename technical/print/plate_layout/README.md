# User plate layout — R17

`r17_plate_layout.3mf` is a publication copy of the four-plate Bambu Studio project added by the user during the repository cleanup. It targets the stored X1 Carbon profile. All four model meshes match the canonical main-part STLs within 0.0002 mm in the source frame; the retained R15-labelled lid model matches the current R16 export of that geometry.

Geometry members, plate transforms, thumbnails and nonfinancial settings are preserved. The publication copy removes the account identifier from model metadata and filament-price fields from the project settings. The unmodified original is retained in the external local archive; original and publication hashes and the changed-member list are recorded in `verification/plate_layout.json`.

No G-code member is present. Existing thumbnail/layer metadata does not establish successful current slicing, printing or acceptance. Inspect settings and layers against the actual printer, nozzle and filament. Complete the fit trials before printing the full body. No knob or coupons are included in this four-main-part project.
