# R17 / D02 complete release

`Plant_Station_R17_D02.zip` contains the current structured technical tree, including three manuals and editable sources, firmware/tests, CAD tools and input, 46 print exports, the user-supplied four-plate 3MF layout, four operator slicer exports, references and verification evidence. `manifest.json` uses repository-relative paths with SHA-256 hashes. `SHA256SUMS.txt` identifies the archive and manifest.

Generated with `python scripts/package_release.py`; every archive member, CRC and source hash is verified during packaging. Old revision ZIPs are retired from the current tree. This is a prototype review release with open physical/electrical acceptance gates; see PROJECT_CONTROL.md.
