# R18 / D03 complete release

`Plant_Station_R18_D03.zip` contains the technical tree: three R18/D03 manuals and self-contained editable sources, unchanged Uno UI v6 firmware/tests, combined R18 CAD entry and frozen evidence, R18 tower/fascia exports, retained lid/planter, fit trials, knob choices, references and verification records. `manifest.json` uses repository-relative paths and SHA-256 hashes. `SHA256SUMS.txt` identifies the archive and manifest.

Previous R17/D02 manuals and release are preserved. R17 source exports, plate project and printer files are historical evidence, not current R18 print choices. The optional route trial checks local clearance; it is not an extra assembly part.

Generated with `python scripts/package_release.py`; packaging verifies members, CRCs and source hashes. This is a prototype review issue. Actual wire bends/retention, new printed fascia, combined dry fit, electrical and wet acceptance remain open. Reported R17 Uno/relay fit closes no controlled action. See [project control](../../PROJECT_CONTROL.md) and [R18 test sheets](../../docs/documents/TS_R18/PLANT-TS-001_R18_D03.pdf).
