# R14 Uno manual reference snapshot

20 September 2026. Supporting evidence for PLANT-AM-R14-UNO Issue A.

`PlantUno/` is an unchanged copy of the existing local bench v2 source, retained with this manual so its electrical configuration can be reproduced. It is not a new firmware release or evidence of a fresh compile/upload. Install the hd44780 library separately; no third-party library code is bundled.

The saved 15 September serial readback reports successful LCD initialisation and motor OFF. It does not qualify the current physical assembly. `evidence_manifest.json` records exact source and log hashes. Motor and optional STOP remain disabled.
